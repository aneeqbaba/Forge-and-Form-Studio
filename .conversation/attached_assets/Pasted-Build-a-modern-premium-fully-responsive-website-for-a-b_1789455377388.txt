Typography
Display/headline font: a bold, tall, slightly condensed serif or slab-serif (e.g., "Fraunces," "Zilla Slab," or similar available Google Font) — used only for large headlines, giving an editorial, premium feel.
Body/UI font: a clean grotesk sans-serif (e.g., "Neue Montreal," "Inter Tight," or "Satoshi" if available; fallback to "Inter" only as last resort but adjust letter-spacing so it doesn't look default).
Headlines are large (48–96px desktop), tight line-height (0.95–1.05), and often break across lines at intentional points, not just where the browser wraps them.
Use generous letter-spacing on small uppercase labels (e.g., section eyebrows like "OUR PROGRAMS") — 0.1–0.15em tracking.
Body text max-width should be constrained to ~60-70 characters per line for readability, never full-width.
Layout & Spacing Philosophy
Break the "centered symmetric block" pattern: use asymmetric grids where headlines are left-aligned or offset, and imagery bleeds to the edge of the viewport on one side.
Vary section rhythm — do not repeat the same layout structure (image-left-text-right) more than twice in a row; alternate with full-bleed image sections, text-only editorial sections, and offset grid sections.
Generous whitespace/negative space between sections (120–180px vertical padding on desktop, scaled down responsively) — nothing should feel cramped or filled just to fill it.
Use a 12-column grid but deliberately let some elements overlap grid lines slightly (e.g., a headline overlapping into the image column) for visual tension.
Avoid uniform rounded corners everywhere — use sharp/square edges on most elements, with rounding reserved only for buttons and small tags, giving a more architectural, premium feel.

Imagery Direction
All imagery should feel editorial and intentional: black-and-white or muted duotone (charcoal/copper toned) photography, dramatic lighting, real movement/action shots — not bright, oversaturated generic stock photos.
Use royalty-free placeholder images from Unsplash/Pexels that match this aesthetic (search terms like "strength training black and white," "gym architecture minimal," "athlete silhouette") rather than default colorful stock photography.
Motion & Micro-interactions
Scroll-triggered fade/slide-up reveals on section content (subtle, 400-600ms, staggered for grouped elements) — used purposefully, not on every single element.
Buttons: on hover, copper CTA buttons should have a subtle fill-direction animation (e.g., background sweeps in from left) rather than a flat color-change.
Images: slight scale/zoom on hover for cards, smooth easing (ease-out, no bouncy/elastic effects).
Navigation underline animations on link hover (thin copper line growing from left to right beneath the link).
No excessive parallax, no spinning icons, no confetti — motion should feel restrained and premium.
Responsive Behavior
Desktop (1440px+): full asymmetric multi-column layouts as described above.
Tablet (768–1024px): collapse asymmetric grids into simpler 2-column or stacked layouts while preserving offset headline styling.
Mobile (below 768px): fully stacked single-column layout, headline sizes scale down proportionally (not just linearly shrunk — maintain visual hierarchy), full-screen mobile nav overlay as described above, touch-friendly tap targets (min 44px), horizontal scroll sections (like coaches) become swipeable carousels with visible partial-next-card peeking (not full-width single cards with dots only).
